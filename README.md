## Hi, I'm Gabi 👋

I build full-stack web applications — React, TypeScript, Next.js, Node — and I've been doing it for over a decade. I run [Digital Lotus Dev](https://digitallotusdev.com), a solo consultancy, and I'm completing an M.S. in Artificial Intelligence at Johns Hopkins.

Lately my work centers on building with LLMs with structured generation and tool use, constraints checked in code rather than trusted, and eval suites that catch regressions.
